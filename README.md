# A股科技+新能源 周度扫描

每周自动扫描科技 + 新能源板块，输出完整投研周报。

## 版本

| 版本 | 脚本 | 数据源 | Windows兼容 | 说明 |
|------|------|--------|------------|------|
| **v3** | `weekly_scan_v3.py` | 巨潮 + 新浪 | ✅ | 推荐使用 |
| v2 | `weekly_scan_v2.py` | 巨潮 + 新浪 | ✅ | 关键词匹配 |
| v1 | `weekly_scan.py` | 东方财富 | ❌ Windows TLS问题 | 仅Mac可用 |

## 快速开始

```bash
pip3 install akshare pandas
python3 weekly_scan_v3.py
```

## v3 功能

- **大盘指数**: 上证/创业板/科创50 周涨跌
- **行业扫描**: 19个科技+新能源行业，1576只股票
- **质量筛选**: PE 3-40 | ROE > 5%
- **输出**: 终端 + `reports/week_XX.md` Markdown报告

## 已知限制

- PE 为年化估算（季报EPS × 4 / 现价）
- 暂无市值过滤（无非东财数据源）
- 暂无持仓体检功能
- Windows 上东方财富 API 不可用（Schannel TLS 不兼容）
