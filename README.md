# A股科技+新能源 周度扫描

每周自动扫描科技 + 新能源板块，输出持仓体检 + 候选标的池。

## 快速开始

```bash
# 安装依赖
pip3 install -r requirements.txt

# 配置持仓（编辑 weekly_scan.py 中的 HOLDINGS 字典）
# HOLDINGS = {
#     "600809": {"cost": 150.0, "date": "2026-06-15"},
# }

# 运行周度扫描
python3 weekly_scan.py
```

## 输出

- 终端直接显示报告
- `reports/week_XX.md` 保存本周完整报告

## 筛选标准

| 指标 | 门槛 |
|---|---|
| PE(TTM) | 3 - 40 |
| ROE | > 5% |
| 市值 | 50 - 10000亿 |

## 覆盖板块

**科技**: 半导体材料、电子化学品、软件服务、第三代半导体、存储芯片、AI概念、云计算、通信服务

**新能源**: 电池、电池化学品、光伏主材、电网自动化、锂电池、固态电池、特高压、动力电池回收
